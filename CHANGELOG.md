# Changelog

All notable changes to this project are documented here. The format follows
"Keep a Changelog"; this project does not use semantic versioning yet
because no release exists.

## Unreleased

### Added

- B-2 scaffold: pnpm workspace frame, ESM-only, with apps/desktop and
  packages core, providers, tools, prompts, ui.
- Section 1 frame files: .gitignore, LICENSE (MIT), CONTRIBUTING,
  CODE_OF_CONDUCT, SECURITY, CHANGELOG, one README per package.
- pnpm-lock.yaml, generated by a real install and verified with
  install --frozen-lockfile (see build-notes.md section 8.4).
- Tests for the 4 real logic files in packages/core
  (packages/core/tests/logic.test.ts), 6 tests, run green with node.
- English translation of all comments and descriptions in the 35 PR files.

### Known gaps (not fixed, still open)

- Cargo.lock and the exact Tauri patch: blocked, no Rust toolchain on the
  build machine.
- Real SDK wiring (createAgentSession import, gate steps, permission
  logic, Tauri invoke): still stubs.
- Name unification: pending the 10/11 decision; all names stay temporary.
- `@sen/*` package scope: proposal only, pending confirmation at review.
- Independent verification of this round: not done by design; the seat
  re-verifies.
