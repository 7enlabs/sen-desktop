# @sen/ui (PROPOSED scope, see note below)

Renderers for tool calls and results, plus themes, for Sen Desktop.

## Role

- Renders tool calls and their results for display.
- Serves themes through the ResourceLoader interface from
  packages/prompts.

## Status

STUB. No real renderer, no real theme, no fake content.

## Package scope note

The `@sen/ui` name is a PROPOSAL pending SD Leader confirmation at review
time. If the scope is not agreed, the fallback is the unscoped name `ui`
before merge. Do not publish under the scope until confirmation exists.
